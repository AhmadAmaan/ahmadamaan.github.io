PROJECT 02 / AI APPLICATION COACH · FULL-STACK

Applywise

An AI application coach that turns a candidate’s experience and a job description into an editable preparation plan. It combines contextual chat, resume bullet drafts, interview questions, and checklists, with persistent session state and checkpointed generation workflows.

Explore the code ↗

The problem

Preparing an application involves repeatedly connecting real experience to a specific job. I built a workspace where a candidate can develop that connection, inspect the generated material, and keep their preparation in one place.

Inside the build

  • Keep useful state across visits. A SQLite-backed Cloudflare Durable Object stores the candidate profile, conversation, plan, and checklist for each browser session.
  • Break generation into recoverable steps. Cloudflare Workflows coordinates analysis, drafting, and next steps, checkpointing results and retrying model failures. Run identifiers prevent stale callbacks from replacing newer work.
  • Put the candidate in control. Plans remain editable and require approval. Structured model outputs are validated, and the app offers contextual interview practice and Markdown export. It does not send applications to employers.

Scope & trade-offs

The application uses anonymous browser sessions rather than a full account system. Local demo mode uses explicitly labelled deterministic responses. Live mode uses Workers AI and requires suitable edge access controls before broad distribution.

What I’d explore next

Add account-based access and recovery, then evaluate the generated plans against a broader collection of roles and experience profiles.
